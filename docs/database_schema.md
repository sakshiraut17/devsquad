# DevSquad Database Schema Specification

DevSquad uses PostgreSQL as its core relational datastore, managed asynchronously in FastAPI using **SQLAlchemy 2.0** and **Alembic** migrations.

## Entity Relationship Summary

```
USERS (1) -------> (*) REPOSITORIES (1) -------> (*) ISSUES
                       |                             |
                       v                             v
                      (*) -----------------------> (*) RUNS
                                                        |
                                                        +---> (*) AGENT_LOGS
                                                        +---> (*) PATCHES
                                                        +---> (*) TEST_RESULTS
                                                        +---> (1) PULL_REQUESTS
```

---

## Table Definitions

### 1. `users`
Stores user profile and GitHub authentication credentials.
- `id` (UUID, Primary Key)
- `github_id` (VARCHAR, Unique, Indexed)
- `username` (VARCHAR, Not Null)
- `email` (VARCHAR, Nullable)
- `avatar_url` (VARCHAR, Nullable)
- `access_token_encrypted` (TEXT, Nullable)
- `created_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)
- `updated_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 2. `repositories`
Tracks connected user repositories.
- `id` (UUID, Primary Key)
- `user_id` (UUID, Foreign Key -> `users.id`, Indexed)
- `github_repo_id` (BIGINT, Unique, Indexed)
- `full_name` (VARCHAR, Not Null) -- e.g., "owner/repo"
- `default_branch` (VARCHAR, Default: "main")
- `is_active` (BOOLEAN, Default: `true`)
- `connected_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 3. `issues`
Cached GitHub issues linked to connected repositories.
- `id` (UUID, Primary Key)
- `repository_id` (UUID, Foreign Key -> `repositories.id`, Indexed)
- `issue_number` (INTEGER, Not Null)
- `title` (VARCHAR, Not Null)
- `body` (TEXT, Nullable)
- `state` (VARCHAR, Default: "open") -- "open", "closed"
- `synced_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 4. `runs`
Represents an execution instance of the multi-agent workflow for a specific issue.
- `id` (UUID, Primary Key)
- `repository_id` (UUID, Foreign Key -> `repositories.id`, Indexed)
- `issue_id` (UUID, Foreign Key -> `issues.id`, Indexed)
- `status` (VARCHAR, Indexed, Default: "pending") -- "pending", "planner_running", "coder_running", "tester_running", "reviewer_running", "awaiting_approval", "pr_creating", "completed", "failed"
- `current_node` (VARCHAR, Default: "planner")
- `retry_count` (INTEGER, Default: 0)
- `total_tokens_used` (INTEGER, Default: 0)
- `estimated_cost_usd` (NUMERIC(10, 4), Default: 0.0000)
- `started_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)
- `completed_at` (TIMESTAMP WITH TIMEZONE, Nullable)

### 5. `agent_logs`
Structured logs generated during agent node execution.
- `id` (UUID, Primary Key)
- `run_id` (UUID, Foreign Key -> `runs.id`, Indexed)
- `agent_name` (VARCHAR, Not Null) -- "planner", "coder", "tester", "reviewer", "orchestrator"
- `log_level` (VARCHAR, Default: "INFO") -- "DEBUG", "INFO", "WARNING", "ERROR"
- `message` (TEXT, Not Null)
- `metadata_json` (JSONB, Default: `{}`)
- `created_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 6. `patches`
Unified code patches generated by the Coder agent.
- `id` (UUID, Primary Key)
- `run_id` (UUID, Foreign Key -> `runs.id`, Indexed)
- `target_file` (VARCHAR, Not Null)
- `unified_diff` (TEXT, Not Null)
- `explanation` (TEXT, Nullable)
- `created_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 7. `test_results`
Captured execution output from Docker Sandbox test runs.
- `id` (UUID, Primary Key)
- `run_id` (UUID, Foreign Key -> `runs.id`, Indexed)
- `exit_code` (INTEGER, Not Null)
- `stdout` (TEXT, Nullable)
- `stderr` (TEXT, Nullable)
- `duration_ms` (INTEGER, Default: 0)
- `executed_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)

### 8. `pull_requests`
Pull Requests created on GitHub following human approval.
- `id` (UUID, Primary Key)
- `run_id` (UUID, Foreign Key -> `runs.id`, Unique, Indexed)
- `pr_number` (INTEGER, Not Null)
- `pr_url` (VARCHAR, Not Null)
- `head_branch` (VARCHAR, Not Null)
- `base_branch` (VARCHAR, Not Null)
- `status` (VARCHAR, Default: "open")
- `created_at` (TIMESTAMP WITH TIMEZONE, Default: `now()`)
